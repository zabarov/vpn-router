# Runtime reconciliation

This journal records sanitized production-first actions and how they were
reconciled with the public source. It never contains server addresses, client
profiles, credentials, raw logs, or private network topology.

- [Open runtime drift](open-runtime-drift.md)
- [Disk exhaustion from repeated failure snapshots](2026-10-27_failure-evidence-retention.md)

Each event states the runtime action, protected state, matching repository
change, verification, and any remaining acceptance gate. A green local test is
not by itself proof that a client VPN session works.
